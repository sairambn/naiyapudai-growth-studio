# Security Policy

## Supported versions

This is a production marketing site. The latest `main` branch is the only actively maintained version.

## Reporting a vulnerability

If you discover a security issue:

1. **Do not** open a public GitHub issue.
2. Email **bnsairam14@gmail.com** with:
   - Description of the issue
   - Steps to reproduce
   - Potential impact
   - Any suggested fix (optional)

You will receive an acknowledgement within a few days. Please allow reasonable time for investigation and remediation before any public disclosure.

Thank you for helping keep the project safe.
