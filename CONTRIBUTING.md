# Contributing

This repository is **proprietary** company property of Naiyapudai.

External contributions are not accepted unless pre-arranged in writing.

Internal / authorized collaborators:

1. Branch from `main`
2. Keep changes focused and typed
3. Run:
   ```bash
   bun run lint
   bun run typecheck
   bun run build
   ```
4. Open a PR with the template
